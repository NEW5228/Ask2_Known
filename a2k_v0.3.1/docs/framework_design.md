# Ask2Know Framework Design v0.3.0

## 1. 定位

Ask2Know 是面向个人和小团队的低样本主动教学训练框架。

它不是固定用途的模型，而是一套可配置的学习流程。用户可以自己决定训练什么，例如水果、宠物、车辆、植物、零件或图标。

## 2. 核心问题

现实任务中常见问题：

- 类别很多，细分复杂。
- 用户拿不到大量数据。
- 用户没有时间做大量标注。
- 新类别不断出现，不能每次都重新训练大模型。
- 模型错了以后，用户不知道该补什么数据。

Ask2Know 的目标是降低：

- 数据量成本。
- 标注成本。
- 重训成本。
- 用户调试成本。

## 3. v0.3.0 核心流程

```text
用户创建任务
↓
用户放入少量已知样本
↓
系统提取基础概念特征
↓
系统建立类别原型
↓
系统识别未知样本
↓
候选差距小时主动提问
↓
用户回答关键问题
↓
系统更新特征权重和问题权重
↓
系统保存经验报告和日志
```

## 4. 当前特征

- color：颜色分布。
- size：图像中目标面积、比例。注意单图大小不等于真实大小。
- contour：轮廓、圆度、形状矩等。
- texture：边缘密度、清晰度变化等。

## 5. 主动提问

系统不确定时，不只是输出低置信度，而是分析：

- 当前最混淆的两个类别是谁。
- 哪些特征相似。
- 哪些特征可能不可靠。
- 应该向用户问什么问题。

## 6. 用户反馈

用户可以告诉系统：

- 某个特征重要。
- 某个特征不可靠。
- 某张图适合或不适合学习。
- 系统判断正确或错误。

系统据此更新：

- feature_weights。
- question_weights。
- prototype_model。
- experience_report。

## 7. 不做的事情

v0.3.0 不做：

- 大规模深度模型训练。
- DeepLabCut 式大量关键点标注。
- 固定某个应用领域。
- 自动理解所有抽象概念。

## 8. 后续方向

- v0.4.0：样本池 confirmed / candidate / rejected。
- v0.5.0：经验库增强与复用。
- v0.6.0：可选种子区域教学，注意不是大量区域标注。
- v0.7.0：Python 包化，支持 pip 安装和命令行。
