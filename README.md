Ask2Know 是一个面向小样本图像识别任务的交互式学习项目。
它的核心目标不是简单地训练一个分类模型，而是尝试让系统在识别不确定时主动“询问”用户，并通过用户反馈逐步形成可积累、可修正、可扩展的视觉经验。

在传统图像分类任务中，模型通常只会输出一个预测结果，例如“这是苹果”或“这是梨”。但在实际使用中，模型经常会遇到相似物体、样本数量不足、拍摄角度变化、颜色差异、背景干扰等问题。Ask2Know 希望解决的正是这类问题：当模型无法非常确定地区分两个类别时，它会主动提出问题，例如询问当前图像更像哪个类别，或者询问用户模型判断错误的原因，如颜色、形状、纹理、结构、背景等因素。

通过这种方式，Ask2Know 尝试实现一种更接近“人教机器学习”的流程：
用户不是一次性准备大量完整数据，而是在系统使用过程中不断补充样本、纠正错误、完善类别知识。系统则根据这些反馈更新经验记录，为后续判断提供参考
