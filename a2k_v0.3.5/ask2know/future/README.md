# Future modules placeholder

These modules are intentionally left as design placeholders for future Ask2Know versions.

Planned directions:

- crawler_external_candidates: collect external candidate images, never directly trust them as confirmed training data.
- visual_concept_layer: global reusable concepts such as round, elongated, clustered, symmetric.
- deep_feature_adapter: CLIP / ResNet / MobileNet feature extraction as optional stronger visual base.

Rule: future modules must not break existing user datasets.
