# Ask2Know Changelog

## v0.3.0

定位：从水果专用演示，升级为用户可配置的通用低样本主动教学训练框架原型。

新增：
- 通用任务初始化脚本 `scripts/init_task.py`。
- 通用配置模板 `configs/task_template.yaml`。
- README 操作指南重写。
- 经验报告 `experience_report.json` 输出。
- 版本说明和后续 pip 包化准备。

保留：
- 少样本样本导入。
- 基础概念特征：color / size / contour / texture。
- 主动自然语言提问。
- 用户反馈更新特征权重。
- 问题权重和提问次数记录。

限制：
- 当前仍是浅层特征原型系统，不是深度学习大模型。
- 真实复杂图片效果有限，适合验证框架闭环。
- 种子区域教学尚未正式实现，后续版本加入。

## v0.2.0
- 加入证据驱动的自然语言问题生成。
- 增加大小可靠性、样本质量问题。
- 改进问题选择，避免一直问同一个问题。

## v0.1.0
- 最小水果 demo。
- 支持特征提取、原型识别、主动提问、反馈更新。
